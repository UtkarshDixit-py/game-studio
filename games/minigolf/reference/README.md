# Mini Golf references

Drop reference material here before running the architect:

- `screenshots/` — phone screenshots of mini golf games you like (course layouts,
  aiming UI, power meter, hole-complete screen). Name them by what they show,
  e.g. `aim-drag.png`, `hole-layout-3.png`, `scorecard.png`.
- `notes.md` — a few lines on what to copy (mechanics, feel, pacing) and what to avoid.

Rules: screenshots are for studying **mechanics and layout only**. Nothing in them
is copied: no names, logos, art, sounds or text. Image files in this folder are
gitignored so third-party material never lands in the repo. `notes.md` is committed.
