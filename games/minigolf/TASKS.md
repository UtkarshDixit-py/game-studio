# Putt Duel — TASKS

Conventions for every task: logic in `src/logic/` imports only `@studio/core`,
no Phaser, no `Math.random`, no `Date`. Scenes only render and forward input.
Vitest files sit beside the logic they test. Playwright specs live in `e2e/`,
run in a phone viewport, and drag with `page.mouse.move/down/move/up` (Phaser
treats mouse and touch as pointers). Name every game object a test must find.
